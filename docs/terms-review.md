# 利用規約原案の採用準備

対象: T-02/T-08/T-19。本文の単一正本は[利用規約原案](terms.md)。原案識別子は `realaddr-event-draft-1`、施行日は未定。`/terms` はこのファイルから初期HTMLを生成する。原案を正式な `TERMS_VERSION` / `VITE_TERMS_VERSION` として採用したものではなく、eventイメージ作成の正式version確認ゲートは未充足のままとする。

## 原案へ反映した確定仕様

- 住所利用の期間はx402の確定支払いで決まる。30日単位で、自動継続課金はしない。World承認は住所購入・更新の条件ではない。
- 同じ契約・owner・policy・宛先の適用済み同意は無期限。期限切れは設定利用だけを停止し、同じ契約のpaid renewal/revivalで再承認を要求しない。宛先変更は新たな人間承認を要し、取消し・security suspensionをrenewで解除しない。
- ENSは任意の初回別料金で、標準とcustomを合算しない。住所更新は購入済みENSの維持を含み、同じleaseの復旧で再課金しない。
- 通常の任意取消は返金しない。照合後に復旧不能な発行失敗が確定した注文だけ、元payerへ同一network/assetで全額を自動返金する。gasは運営負担、他の有効期間・商品へ影響させない。強行法規上の権利を除外しない。
- eventはtestnet。実郵便受領・発送・送料決済を含まない。機能の実装・外部接続・公開を完了済みと表現しない。

## 正式採用前の確認事項

以下は原案作成で確定したことにはしない。提供条件を変更する場合は、要件・料金・API・画面の影響を先に確認する。

| 項目 | 必要な確認 |
| --- | --- |
| 本文と施行 | 運営者による本文確認、正式version、施行日、適用対象環境を確定する。原案識別子をそのまま正式設定へ流用しない |
| 申込主体と代理 | 個人・法人等の受付範囲、代理権の確認方法、年齢等の利用資格を確定する。AgentやWorld認証のみを法的主体・代理権・KYCの証明にしない |
| 連絡と表示 | 利用者が使える問い合わせ窓口、通知方法、必要となる事業者表示を確定する。未確認の連絡先や提供拠点を作らない |
| 情報の取扱い | データ項目、目的、providerへの提供・委託、保管場所・保存期間、削除・開示等の窓口を整理し、プライバシー案内を用意する。未確認の保存期間や外部サービス保証を約束しない |
| 法務確認 | 住所の許容用途、契約成立・代理、返金、停止・終了、責任、準拠法・管轄、表示義務について、実際の提供形態に即して確認する。原案第15条の日本法・法定管轄も採用案であり確定済み判断ではない |
| 正式同意の記録 | 公開する確定本文と署名に含むversionを一致させ、本文と適用時点を追跡可能にする。既存の開発用署名を後から新規約への同意とみなさない |

原案の確認ページは `noindex,follow` とし、sitemapとllms.txtには掲載しない。公開ナビゲーション・footer・利用者認証前の利用条件から到達できる。閲覧は同意を意味しない。正式採用時は表示と索引方針を再確認する。

## 条文作成時の法令資料

責任の一律免除や法令上の取消し・解除権の排除を避ける確認資料として、消費者庁の[消費者契約法逐条解説](https://www.caa.go.jp/policies/policy/consumer_system/consumer_contract_act/annotations)を参照した。これは個別条項の適法性確認や専門家の確認が済んだことを意味しない。
